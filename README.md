# honey ♥

A tiny love letter made of **“I love you” in many languages**.

## The experience

- Deep black and wine-red atmosphere with a soft glow.
- Words appear one by one, tracing the heart outline first and then filling its centre.
- A little message appears when the heart is complete.
- Replay button to watch the animation again.
- Responsive layout and reduced-motion support.

## Run locally

Open `index.html` in a browser. No build step or dependencies required.

## Deploy to Vercel

Import this repository in Vercel. It is a static site, so leave the framework preset as **Other** and the build command empty. The output directory can be left as the project root.
